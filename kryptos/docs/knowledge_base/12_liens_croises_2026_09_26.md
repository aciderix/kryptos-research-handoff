## 1. Secret Past (1992) — copie de K4 antérieure à *Antipodes*

- **Fait.** Liste de dépôt de la galerie Nancy Drysdale, 15/09/1992 (IMG_1485, base 05 §7) :
  « 5. SECRET PAST (Courtyard) : 1/2 Cyrillic Alphabet and KGB document, **1/2 duplicates
  text of Kryptos at CIA Headquarters**. Copper, Petrified wood. 80″ × 45″ × 13″ ».
- **Pourquoi ce serait un levier.** C'est une **copie physique du texte de Kryptos de
  1992**, soit **cinq ans avant *Antipodes*** (1997, dont le K4 est identique lettre pour
  lettre au cuivre — vérifié, base 05). Sanborn corrige parfois des coquilles entre copies
  (UNDERGROUND rectifié dans *Antipodes*). Si *Secret Past* montrait un K4 **différent**
  (état antérieur à une correction), on tiendrait une piste directe sur **quelles lettres
  de K4 sont des erreurs** — ce qui vaut de l'or vu le taux d'erreur de Sanborn.
- **Recherche externe (26/09).** Aucune photo publique. L'œuvre **n'apparaît pas** sur le
  site de l'artiste (jimsanborn.net ne liste, pour 1992, que les séries *Archeotranscription*,
  *Filter* et *Clandestine Device 3*). La base amont la donnait déjà « chez un collectionneur
  privé, aucune photo publique » (base 10 F ter, lettre Drysdale 1995).
- **Verdict.** **RADAR — en attente d'une photo.** Rien à calculer sans l'image. Si une
  photo lisible du K4 de *Secret Past* apparaît : comparer ses 97 lettres et son « ? » au
  cuivre de Langley (procédure = celle d'*Antipodes*).

## 2. Code Room / Covert Obsolescence (1991–1993) — main propre de Sanborn, déjà testée

- **Fait.** Exposition *Covert Obsolescence* au Corcoran (*The Code Room* + *The Listening
  Post*) ; cylindre perforé projetant un texte codé (moitié CIA, moitié KGB), avec le mot
  **MEDUSA** enchâssé (*Washington Post* 1991 : « "Medusa" is the key word to the cipher of
  "Code Room" »). Textes tirés de documents CIA/KGB (Library of Congress).
- **Antériorité / structure.** Les feuilles de chiffrement russes manuscrites de Sanborn
  (AAA 6/8, base 05 §6) sont les **feuilles de travail de cette famille** : **Quagmire II**,
  alphabet chiffré à mot-clé **ТЕНЬ** (« ombre »), clé **МЕДУЗА**, recoupé indépendamment
  avec le *Cyrillic Projector* (déchiffré en 2003 ; ЙБАСГТ = МЕДУЗА lu dans ТЕНЬ).
- **Pourquoi ça ne rouvre rien pour K4.** Ce répertoire est celui que **Sanborn manie
  seul** (K1–K2, variante de convention), **pas** le système de K4. Et il est **déjà testé
  exactement** contre K4 :
  - `audits/visible_words_2026_09_23/` : le **montage MEDUSA** (mot-alphabet + mot-clé),
    QI–QIV, tous mots visibles → **éliminé** (aucun signal).
  - `audits/keyword_alphabet_2026_09_23/` : **Quagmire II** (et I, IV) avec **tout** alphabet
    à mot-clé (préfixe L ≤ 12), Vig/Beau, périodes 1–52, test exact, 350/350 contrôles →
    **éliminé** sauf la période 19/38 (= coïncidence de Bean à distance 38, hasard).
  - `audits/moteur_2026_09_25/` : 1,4 M d'alphabets à mot-clé × QI–QIV, témoins → sans signal.
- **Verdict.** **Clôturé.** Un relevé public des textes de *Code Room* / *Covert Obsolescence*
  confirmerait la méthode connue de Sanborn (Quagmire II / MEDUSA) ; il **n'apporterait pas**
  le système de K4 (que la base attribue plutôt à Scheidt, apporté voire exécuté par lui).
  Valeur pour K4 : faible. Non prioritaire.

## 4. Le « masque » de Scheidt → tentative de recette testable

Formulations de Scheidt (base 09 §2.2) : « retire le biais / l'avantage de l'anglais »
(2004, 2007) ; « change la base de **langue**, pas vers une autre langue, vers autre chose »
(2020) ; « fonction régénérative » (2011) ; code « **réfléchissant**, pas symétrique » (2007) ;
résultat « **comme un masque jetable**, obtenu autrement » (2020) ; ordre non dit. Refusé :
la base **mathématique** (base 2/16) et les langues rares.

Réduction en recettes, et pourquoi chacune retombe **dans la portée déjà testée** :
- « retire le biais / aplatit l'anglais » → **aplatissement de fréquences**. À 26 lettres,
  une substitution mono conserve les fréquences ; il faut du polyalphabétique (déjà le cœur
  testé) ou des symboles homophones > 26 → **alphabets étendus 27–30 / Vigenère homophone,
  éliminés** (base 02 §2.1) ; « changer la base » (codages 5 bits + XOR, groupes d'ordre
  26–36) → **éliminé** (base 02 §2.6, T36).
- « fonction régénérative » → **flux de clé auto-généré** : autoclé (clair/chiffré, tous
  écarts), LFSR ordre 1–5, Gromark/chaînes → **tous testés** (base 02 §2.2, §2.6 ; T23, T27,
  T34, LFSR/Fibonacci).
- « réfléchissant, pas symétrique » → indice de convention **Beaufort** (réciproque) vs
  Vigenère : déjà couvert partout (Vig/Beau/variante systématiques).
- **Écho thématique** (sans valeur de recette) : les *Filter* de 1992 (*Bias Filter* INCLINARE,
  *Shadow Filter* OMBRE, *Deceit Filter*, *Light Filter* CBET = СВЕТ « lumière ») tournent
  autour de « filtrer le biais » — même vocabulaire que le masque. C'est une **résonance
  d'atelier**, pas un chiffre.
- **Verdict.** Aucune réduction concrète du « masque » à 26 lettres, réversible à la main,
  ne sort de la portée déjà éliminée. Là où il **sortirait** (étape qui n'est **pas** lettre
  à lettre), les 24 lettres cessent de contraindre : c'est exactement le cas indécidable de
  la base 09 §6, qui demande une **donnée nouvelle** (K5).
