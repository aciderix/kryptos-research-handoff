OTP, One Time Pad, Decryption Step:
The next step involves treating W1 as a pad and K4 as a ciphertext as part of a OTP, 
one time pad, encryption scheme.  In this scheme, one uses the pad as a 'key' and K4 
as the ciphertext to recover the plaintext using the Kryptos Vigenère cipher, as was 
used in K1 and K2.  Use the following notation:
For encryption: ENC(key, plaintext) = ciphertext
For decryption: DEC(key, ciphertext) = plaintext
Examples:
key = ELYOIE, plaintext = BERLIN, ciphertext = NYPVTT
ENC(ELYOIE, BERLIN) = NYPVTT
DEC(ELYOIE, NYPVTT) = BERLIN

[[page 4]]
For ease, I have provided a python script that automates this in my folder in the Yahoo 
Kryptos Group Files under personal folders, or one could use one of the interactive 
keyed Vigenère solvers on the web like Rumkin's Keyed Vigenère Cipher at 
http://rumkin.com/tools/cipher/vigenere-keyed.php
