I have Brute Morse Attacked­™ all of the morse code and posted the results here.

The way I did this:

1. I compiled a dictionary file containing 5.8 million English words, names and abbreviations.
2. I wrote a program to translate these words to morse
3. I checked the resulting morse code with the morse code from the site to see if any long interesting words can be formed directly from the code.

Each piece of morse code has several result files:

(XXX = name of the morse code piece compared)

1. longmorseXXX.txt : morse code sequences of 15 dits/dahs or longer
2. longwordsXXX.txt : resulting words with more than 5 characters
3. resultsXXX.txt   : the complete results

Also, for each of the above file there is a file with the results when the entire morse code sequence from Kryptos would be written backwards.

The words Kryptos, Abscissa, Palimpsest do not appear in any file (to save you the trouble)
