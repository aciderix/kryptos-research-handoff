This file describes my attempts to decode section 4 on the assumption that is uses a Morse code-based encryption scheme.I converted the text for section 4 to morse code and ran a program that looks for Morse words of length 7 or more morse characters within the Morse representation of the code. I used a dictionary of 17500 words (which included a few extra words such as Kryptos that I thought might be interesting; none of those extra words came up at all in my testing). While I was at it, I also searched for sequences of two or more Morse digit in a row, and also specifically counted instances of words such as "the" and "and".First, though, I tested some known cases to obtain something to compare with. All the tests I ran used a string of morse code the same length as the representation of section 4. I tested 1024 examples of the following cases:1.	Sequences of random letters of the alphabet, converted to morse code2.	Sequences of letters selected randomly but with a distribution the same as that of English text3.	Sentences of English text selected at random from a total of 1MB of prose.My results for these are given in Table 1. You can see that distributions 1 and 2 differ by about 1-2 standard deviations. This means that although it is possible to distinguish the two distributions given a large data set, for an individual test case itÕs impossible to tell with any confidence which of the two categories it belongs to. Distribution 3 differs from random text by nearly 7 standard deviations for shorter words (falling to 3.5 standard deviations for longer words). This means that a single example can confidently be said to be English text rather than a random distribution.However, it is also easy to concoct examples that are indistinguishable from random text (by using lots of short words and few long ones). If a length of cyphertext is found to have a distribution that differs significantly from that expected of random text, then it is very likely to be genuine English text, and an attempt should be made to recover the plaintext - but if the distribution is not significantly different to a random one, then that does not necessarily mean it has not been encoded in this way.Because I think the palindromic nature of the morse messages around the sculpture is in some way significant, I ran the program with the section 4 morse reversed, with individual letters within it reversed and both; and tried each with dictionaries where the words had been given each of these treatments (i.e. 16 scenarios, some of which were redundant). While I'm actually inclined to think that the palindromes may have a deeper significance than that, it was the only relevance I could think of to this decryption method.The 8 test cases were:1. Cyphertext read forwards, looking for morse words2. Cyphertext read forwards, looking for morse words with individual letters coded in reverse3. Cyphertext read forwards, looking for morse words whose entire encoding is reversed4. Cyphertext read forwards, looking for morse words with letters in reverse order5. Cyphertext read backwards, looking for morse words6. Cyphertext read backwards, looking for morse words with individual letters coded in reverse7. Cyphertext read backwards, looking for morse words whose entire encoding is reversed8. Cyphertext read backwards, looking for morse words with letters in reverse orderTable 2 gives my results for the number of words of each length found for the 8 test cases. The results do not provide any conclusive evidence that any of the 8 cases are anything more than a random string of morse code.Table 3 lists all the long words found in each of the test cases, and also cases where two long words appear next to each other. I could not see anything that looked promising in those lists.There is one more big flaw with this theory: there is no key. In other words, there is no extra piece of knowledge that can be used to make the decryption trivial. As it is, decryption is a tough task for *everybody*. In my mind this pretty much rules out the theory.Alex green suggested an encryption scheme based on morse code which is keyed and involves using a key to permute the letter spacings in a morse message. In its simplest form this scheme will preserve the number of roman-alphabet letters having a given length in morse code, although the letters themselves will be altered. Looking at that, I get the following results for the ratio of one : two : three : four-morse-character words:Expected English0.217348 : 0.242273 : 0.320040 : 0.220339Sample English text16 : 22 : 37 : 2215 : 19 : 45 : 18Start of section 3 (which is English text subject to a route transcription)14 : 27 : 27 : 29Section 48 : 12 : 41 : 36The fact that section 4 doesnÕt correspond particularly well to the expected English distribution implies that it is probably not encoded using such a scheme, but it might be worth investigating further.Hopefully this will save other people from duplicating effort in this area. I don't want to discourage anybody - as I said before I personally think that morse and palindromes will feature in the solution somewhere. This just shows that any decryption method is a bit more complex than the methods IÕve considered here.Please point out to me  if I've missed anything in what I hope was a fairly thorough investigation of this area.Jonny === TABLE 1 ===In the following lists words of 1-6 morse characters in length have been omitted, and the first figures given are for 7-character words.Random
