Some modulo 26 arithmetic to better understand the algorithm. It's just additions and 
subtractions, no rocket science here. The Vigenere or Quagmire III ciphers (like the one used in 
K1 and K2), if we use the ordinal numbers of the alphabet, can be expressed like this: 
 
Cipher  P(i) + K(i) = C(i)        Decipher  C(i) - K(i) = P(i)        Using the Kryptos alphabet 
 
Very simply, for each character of the plaintext P that occupies place i, the key K corresponding 
to place i is added to it and the ciphertext character C of place i is obtained. Something similar 
happens when we decipher. 
 
For the algorithms we are using it is a little longer to explain. I'm going to use Tip T instead of 
Pointer so it doesn't get confused with plaintext P. 
 
Decipher T(i-1) - J(i) + C(i) = K(i) Using the ABC alphabet 
 
It is also simple, the pointer or Tip of the previous place T(i-1) is taken, the jump J(i) 
corresponding to the place i is subtracted, the cipher character C(i) of the place i is added and 
we obtain the key K(i) of place i. Always using the ABC alphabet. Then, using the Kryptos 
alphabet, with the key K(i) and the cipher C(i) we obtain the plain P(i). 

[[page 10]]
 
These are asymmetric algorithms, in the sense that we can always decipher but we cannot 
always cipher. To decipher given a pointer or tip T, a jump J and a code C we can always find a 
key K and therefore a plain P. But to cipher it is not so simple. We must find a pair K(i) and C(i) 
that with the alphabet ABC complies with: 
C(i) - K(i) = J(i) - T(i-1) 
And at the same time with the Kryptos alphabet complies with: 
C(i) - K(i) = P(i) 
Depending on the P(i) that we want to cipher and the corresponding jump, there are times 
when there is no K(i) and C(i) pair that meets both conditions. That is why I have the theory 
that this algorithm only gives us clues to find parts of the K4 plaintext or we must modify it in 
some way or apply it in a different way. Unless the plaintext has been chosen so carefully that 
K and C pairs that satisfy the conditions always correspond. 
With Anders' recent observation that part of the words appear correct and the parts that are

wrong characters are very close to the correct ones in the Kryptos alphabet: Y+1 = P, D+1 = E, 
T+2 = S and O-1 = T. So #35 PALIMPSEST is a good candidate for plaintext and its place is next 
to EASTNORTHEAST. It is as if there is a small noise at the end of the words. Is this the way Jim
