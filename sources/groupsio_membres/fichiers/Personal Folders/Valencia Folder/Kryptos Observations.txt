							  By Ruben Valencia

I have something interesting to share with the group. Before I do that, you should view the CIA ARTS X TEST video I posted on my YouTube account about a year ago, as I'll be using that same method in this disclosure. I wanted to start by saying that I'm not making any claims with this work. I just want to share my observations, recent findings, and method for the community take a look. Whatever is seen or not seen is perfectly ok. I was stuck after creating the ARTS X TEST matrix. However, my mind kept working on it.


In the ARTS X TEST matrix, I used every 7th character, wrote it down, then removed it. I repeated this process to create that matrix.
One night while reading, I found something odd inside of a declassified NSA document:

https://www.nsa.gov/portals/75/documents/news-features/declassified-documents/cia-kryptos-sculpture/KRYPTOS_Summary.pdf

Per the last page of the document, it reads:

"There are no long repeats, but there is a slight interval 7 property."

"I have tried a number of things which might cause an interval 7 property to appear, including' Plaintext Autokey and Ciphertext Autokey, but I've yet to stumble upon something that gives either readable plaintext, or hints at the presence of a second encipherment layer."

I used a repeating process with the interval of 7 to create the ARTS X TEST matrix. That matrix stopped my other work and I began to focus on this. I spent some time thinking and finally came up with an idea that uses that same method, at different intervals/offsets, with one addition. It has produced some interesting results. I won't release them all in this document, but if you follow what I've done, you can start your own search for the rest that I have found, or have yet to find. I will share what I have been working on now.
