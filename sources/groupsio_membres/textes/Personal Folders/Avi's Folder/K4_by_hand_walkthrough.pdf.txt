1. Introduction
This walkthrough demonstrates how to decrypt K4 using only: • The 97-character K4
ciphertext • Four known plaintext segments (cribs) • Basic modular arithmetic (mod 26) •
Pencil and paper
The method uses a polyalphabetic cipher system with: • Six cipher classes determined by
position • Three cipher families (Vigenère, Beaufort, Variant-Beaufort) • Periodic key wheels
with period 17
What You'll Learn:
1. How the classing function assigns each position to a cipher class
2. How cribs force specific key values
3. How forced values propagate through the periodic structure
4. How to decrypt any position once you have the key wheels

5. Building the Key Wheels
Each class has a key wheel with period 17. To determine a key value: 1. Calculate the class:
class(i) = ((i mod 2) × 3) + (i mod 3) 2. Calculate the wheel slot: slot = i mod 17 3. Apply the
cipher formula with the crib to find the key
Example: Position 21 (EAST)
• Ciphertext: F = 5, Plaintext: E = 4 • Class: ((21 mod 2) × 3) + (21 mod 3) = (1 × 3) + 0 = 3 • Slot: 21
mod 17 = 4 • Cipher: Vigenère, so K = C - P = 5 - 4 = 1 (letter B) • Result: Class 3, Slot 4 → Key = B

[[page 7]]
6. Propagation: How Cribs Determine the Wheels
The four cribs provide constraints at 22 positions. Due to the period-17 structure, these
constraints propagate to force many more key values.
Propagation Example
If position 21 forces Class 3, Slot 4 to have key B, then: • Position 38 (= 21 + 17) also uses Class 3, Slot
4 → Same key B • Position 55 (= 21 + 34) also uses Class 3, Slot 4 → Same key B • Position 72 (= 21 +
51) also uses Class 3, Slot 4 → Same key B • Position 89 (= 21 + 68) also uses Class 3, Slot 4 →
Same key B This propagation means the 22 crib positions actually determine most of the key wheels.
Algebraic Determination
Through this propagation process: • 71 positions become algebraically determined • 26 positions
remain undetermined (require additional constraints) The 26 undetermined positions are resolved using
the tail constraint (positions 75-96).

7. Worked Example: Positions 80-84
Let's decrypt positions 80-84 step by step, showing the complete process.
Position 80: T → O
1. Calculate class: ((80 mod 2) × 3) + (80 mod 3) = 0 + 2 = 2
2. Calculate slot: 80 mod 17 = 12
3. Look up key: Class 2, Slot 12 → K = 7 (H)
4. Apply Beaufort: P = K - C = 7 - 19 = -12 ≡ 14 (mod 26)
5. Convert: 14 = O
Position 81: J → F
1. Calculate class: ((81 mod 2) × 3) + (81 mod 3) = 3 + 0 = 3
2. Calculate slot: 81 mod 17 = 13
3. Look up key: Class 3, Slot 13 → K = 4 (E)
4. Apply Vigenère: P = C - K = 9 - 4 = 5
5. Convert: 5 = F
Position 82: C → A
1. Calculate class: ((82 mod 2) × 3) + (82 mod 3) = 0 + 1 = 1
2. Calculate slot: 82 mod 17 = 14
3. Look up key: Class 1, Slot 14 → K = 2 (C)
4. Apply Vigenère: P = C - K = 2 - 2 = 0
5. Convert: 0 = A

[[page 9]]
Position 83: D → N
1. Calculate class: ((83 mod 2) × 3) + (83 mod 3) = 3 + 2 = 5
2. Calculate slot: 83 mod 17 = 15
3. Look up key: Class 5, Slot 15 → K = 16 (Q)
4. Apply Vigenère: P = C - K = 3 - 16 = -13 ≡ 13 (mod 26)
5. Convert: 13 = N
Position 84: I → A
1. Calculate class: ((84 mod 2) × 3) + (84 mod 3) = 0 + 0 = 0
2. Calculate slot: 84 mod 17 = 16
3. Look up key: Class 0, Slot 16 → K = 8 (I)
4. Apply Vigenère: P = C - K = 8 - 8 = 0
5. Convert: 0 = A
Result: TJCDI decrypts to OFANA (part of "JOY OF AN ANGLE")
