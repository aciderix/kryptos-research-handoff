Kryptos K2/K4 Internal Variant System
Proposed Method That Was Used to Build K4
Start with by populating a 26 x 26 matrix of character lookups with, say 
12.6% E's e.g. 26x26x0.126 --> 85 or even those crypto FM phrases like 
SIXTYSEVEN, LUCKYCHARM, MASTERWORK etc... (this hides the English 
frequencies)
Using K2 as your random X reference character (“Q”) find one of your K4 
PT character in that same row (“I”) and pick its Y column reference (“T”)
“T” then becomes your K4 CT for that position
If you start seeing too many bigrams/trigrams, go back and choose an 
alternative letter from the original selections.
Publish the string of Y references as the CT code 
Add fours character to the front of the CT code (modified with ROT-13) to 
indicated where to find the other half of the bigram OBKR/BOXE
1st Steps Working Backwards to Solve
start with an empty 26 x 26 matrix for the bigram characters (different row/
column counts could apply but we can compress/collapse later)
fill in the known cribs/letters into the array
regenerate all of K4 with the new matrix
