2. 
 
There are 3 typos in plaintext. 
 
Q > IQLUSION 
U > UNDERGRUUND 
A > DESPARATLY 
 
“Q” is 25th character in the row that contains “IQLUSION” word. 25th 
character of English alphabet is “Y” 
 
“U” is 24th character in the row that contains “UNDERGRUUND” word. 
24th character of English alphabet is “X” 
 
“A” is 11th character in the row that contains “DESPARATLY” word. 
11th character of English alphabet is “T” 
 
The K2 solution key is “ABSCISSA”.  
 
Abscissa : The vertical and horizontal lines that make up the 
quadrants of a coordinate plane. The vertical axis is usally 
referred to as the “Y” axis and the horizontal axis is usually 
referred to as the “X” axis.
