Note that the following notation is used to denote using the Kryptos Vigenère cipher:
For encryption: ENC(key, plaintext) = ciphertext
For decryption: DEC(key, ciphertext) = plaintext
Examples:
key = ELYOIE, plaintext = BERLIN, ciphertext = NYPVTT
ENC(ELYOIE, BERLIN) = NYPVTT
DEC(ELYOIE, NYPVTT) = BERLIN
