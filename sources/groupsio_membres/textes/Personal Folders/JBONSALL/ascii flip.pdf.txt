Hypothesis:
That flipping bits of characters' ASCII codes might be a "masking technique" for one step of K4 decryption. It would require that the mistakes in 
IQLUSION (L->Q) and UNDERGRUUND (O->U) are suggestive of the bit-flip technique, and the raised letters in dYAhR (01101 where 1 is raised) 
indicate which bits to flip.
Result:
The ASCII code bits to go from O->U follow this pattern.
The ASCII code bits to go from L->Q do not.
Conclusion:
Perhaps this is a valid theory which should be investigated more, but the IQLUSION "mistake" is unrelated?
