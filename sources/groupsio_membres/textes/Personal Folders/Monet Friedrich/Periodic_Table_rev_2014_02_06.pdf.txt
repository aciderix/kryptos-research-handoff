The Periodic Table provides the means to build a running cipher. 
XORing this running cipher with the reverse of the K4 CT, aligned according to well documented clues, provides interesting results.

The periodic table has changed since the dedication of Kryptos on November 3rd, 1990. 
In 1994, the names and symbols of a few of the elements were officially settled upon, 
 
effectively changing what are currently the last few entries of the periodic table.
