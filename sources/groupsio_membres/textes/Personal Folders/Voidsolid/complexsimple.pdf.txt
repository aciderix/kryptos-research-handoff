However, a variant of the enigma machine with three rotors and no reflector 
that can  be done very practically easily and quickly with paper and pencil 
is possible and is certainly not complex in this respect. 
Without a reflector it is simply just substitution in succession with three 
different rotating alphabets, each of which are rotating at different, but 
constant rates. The three alphabets can be three different single strips of 
graph paper with 26 squares each that is the alphabet copied twice as well 
as one for the alphabet. For example, the kryptos alphabet, the kryptos 
alphabet reversed, and the alphabet reversed, and the alphabet itself. 
Now we just need the rotor stepping and the starting vector. This would be 
a two 3 character strings. Note that each step is one letter, however we 
could also add another three characters for a different number of 
characters stepped by. We could also have it more simple like mod 2 or mod 
3 etc. 
First write the pt with each character on a new line, next write the 
starting vector next to the first pt character. next copy each character in 
the starting vector on the first line the corresponding number of times in 
the corresponding character in the rotor stepping, then increment, and 
repeating. 
Now to encipher any pt character, first put each of the three alphabet 
strips with the first letter of each strip under the corresponding letter 
of the normal alphabet strip. Now find the pt character in the normal 
alphabet and find the letter exactly below it in the first alphabet strip, 
now repeat this process with the new letter, find it in the normal alphabet 
and return the letter below it in the second alphabet strip, now repeat 
with this newer letter, find it in the normal alphabet and return the 
letter below it in the third alphabet strip. 
For example, if the stepping is abc and the starting is kry
