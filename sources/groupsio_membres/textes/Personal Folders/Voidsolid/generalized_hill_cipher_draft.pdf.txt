generalized_hill_cipher (w/ nice playfair, w/ nice binary)  
S1 derive structure of non-square matrix from berlin clock
1 = uO                                   O = circle          u = yellow
2 = nW nW nW nW                          W = square          n = red
3 = nW nW nW nW                          V = rectangle           
4 = uV uV nV uV uV nV uV uV nV uV uV
5 = uW uW uW uW
-------------------------------------------------------------------------------
step 1 {substitute uO -> nV}            |step 3 {transpose 3 <-> 4}&
                                        |       {wrap 4 to width 3}           
  1 nV                                  |
  2 nW nW nW nW                         |  1 nW nW nW nW    4 uV uV nV
  3 nW nW nW nW                         |  2 nW nW nW nW    5 uV uV nV          
  4 uV uV nV uV uV nV uV uV nV uV uV    |  3 uW uW uW uW    6 uV uV nV
  5 uW uW uW uW                         |                   7 uV uV nV
-------------------------------------------------------------------------------
step 2 {concatinate 4 -> 4 1}           |step 4 {partition 123 into matrix B}&
                                        |       {partition 4567 into matrix E}
  1 nW nW nW nW                         |                                       
  2 nW nW nW nW                         |     B                E
  3 uV uV nV uV uV nV uV uV nV uV uV nV |     | nW nW nW nW |  | uV uV nV |     
  4 uW uW uW uW                         |     | nW nW nW nW |  | uV uV nV |     
                                        |     | uW uW uW uW |  | uV uV nV |
                                        |                      | uV uV nV |
-------------------------------------------------------------------------------
B=Substitute(E^T,{u->n, V->W})           ^T is MatrixTranspose
E=Substitute(B^T,{n->u, W->V})
S2 derive the structure of the functions
nW*x = (noW)(x) = W(n(x))    n = u^-1    n,u,W,V are functions
uW*x = (uoW)(x) = W(u(x))    u = n^-1    ^-1 is function inverse
nV*x = (noV)(x) = V(n(x))    W = V^-1    o is function composition
uV*x = (uoV)(x) = V(u(x))    V = W^-1    x is any string
S3 derive the structure of the input and output of the functions
plaintext    P3 = | P31 P32 P33 |               P4 = | P41 P42 P43 P44 |
ciphertext   C3 = | C31 C32 C33 |               C4 = | C41 C42 C43 c44 |
             3 strings of 32 characters each    4 strings of 24 characters each
for example, we can define these c3 and c4 explicitly by partitioning k4 into
12 equal pieces of 8 characters each in four ways by removing singleton
characters M or Y or both. For "Y" there are 64 characters to the left and
32 characters to the right. For "M" the divisions are different. see *page2
there are two characters whose count is 1 in k4: Y and M, if Y or M is removed,
the ct has 96 characters and 25 different characters like 1-1 perfect playfair 
if both y and m are removed there are 24 different characters in k4, so it can
be converted into 5bit perfect binary 1-1 mirror 1-1 complement see *page2
S4 define the structure of the relation from the ct to pt
                                                                                
the relation is only one of the four maps:                                      
                                                                                
1 B.C4^T=>P3^T   3 B.P4^T=>C3^T     . is Matrix*    A must havegeneralized ^-1  
2 E.C3^T=>P4^T   4 E.P3^T=>C4^T     A is (B or E)   A^-1 (Ax=b=>AA^-1b=b)
