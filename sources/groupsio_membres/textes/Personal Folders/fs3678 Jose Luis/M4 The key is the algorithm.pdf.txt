M4  The key is the algorithm 
 
Canadian member diconaxes@yahoogroups found a pattern linking NYP to ELY and VTT to OIE. 
His messages, signed as Todd, are #11858 and #11862 in Groups.io. This was his last message 
(as WW) in April 2011. I couldn't find the excel file that Todd shared. If anyone can reach Todd 
or has his file and can share it, would be great. Todd found a pattern to obtain from NYP the 
key ELY and from VTT the key OIE (the keys of BER LIN), using the normal alphabet ABC… Z. If 
we number A(1), B(2), C(3)… Z(26), the simple algorithm in modulo 26, which we call the Todd 
or T algorithm, is the following: 
 
For NYP, initial position = 17 
17 + N(14) = 5(E)    17 - 4 + Y(25) = 12(L)    17 - 4 - 4 + P(16) = 25(Y) 
 
For VTT, initial position = 19 
19 + V(22) = 15(O)    19 - 4 + T(20) = 9(I)    19 - 4 - 4 + T(20) = 5(E) 
 
So, if this could be applied to K4, starting from a pointer or initial position, subtracting with 
jumps from 4 to 4, we obtain the position for each character of the ciphertext, then we add 
the code character and obtain the key, always with the alphabet ABC… Z. Then, using the 
alphabet KRYPTOS, with the key and the code we obtain the plaintext. That this algorithm does 
not work between P and V is not surprising, since as we saw in message M1 the rows slide to 
form BLUE, so the V is not encoded after P. In principle, the algorithm it is encouraging: it is 
simple and uses both alphabets (the alphabet ABC… Z is in the panel for something, right?). But 
the algorithm does not work with CLOCK.

Member Ferdinando Stehle from Italy, found a pattern in K4's DIAWINFBN sequence. I have 
been able to locate messages #33, #71 and #230 about it. Ferdinando's last message was in 
May 2015. He shows the pattern in two ways, always using the normal alphabet ABC… Z and 
modulo 26. The first way, if we subtract for each character the previous one, repeats the same 
pattern of 4 numbers: I(9) - D(4) = 5, A(1) - I(9) = 18, W(23) - A(1) = 22, I(9) - W(23) = 12 , N(14) 
- I(9) = 5, F(6) - N(14) = 18, B(2) - F(6) = 22 and N(14) - B(2) = 12. The pattern is 5, 18, 22, 12, 5, 
18, 22, 12. The second way, if we subtract from each character, the character four places back, 
you get the constant jump of 5: I(9) - D( 4) = N(14) - I(9) = F(6) - A(1) = B(2) - W(23) = N(14) - I(9) 
= 5. Both the Ferdinando pattern like Todd's they use the common alphabet and modulo 26. 
While Todd's has jumps of 4 between consecutive characters, Ferdinando's has jumps of 5 
between characters separated by 4 places. So let's try different jumps. We will call this first 
expansion of the algorithm the Todd Ferdinando or TF algorithm.
